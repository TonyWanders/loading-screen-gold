A program that writes one loading-screen tip to `/output/entry.txt`,
for the make.fun competition
[Loading Screen Gold: A Tip in 200 Characters](https://make.fun/bounty/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270).

Run it with Python 3:

```
python3 main.py
```

It writes the tip below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The tip is 143 characters, inside the 1 to 200 gate, one
line, no em dash.

## The tip

```
Tip: your agent just rewrote your code while you blinked. Read the diff, keep what works. You are the senior now, and your intern never sleeps.
```

## Why this tip

It is a real tip, not a slogan: read the diff and keep what works.
It speaks to both sides of the screen at once. The developer is the
senior reviewer now, and the agent is the intern who never sleeps.
The joke lands in one glance, and it stays clear of the usual coffee,
deadline and compile jokes.
